# Send Mail API

API para envio de e-mails, desenvolvida em **Java** e **Spring Boot**.  

Utiliza o **Spring Mail** para envio de mensagens via SMTP.

## 🚀 Tecnologias Utilizadas

- **Java**: Linguagem principal do projeto.
- **Spring Boot**: Framework para construção da API.
- **Spring Mail**: Biblioteca para envio de e-mails via SMTP.
- **SMTP**: Protocolo utilizado para envio de e-mails.

## ✨ Funcionalidades

- **Envio de E-mails Simples**: Permite enviar e-mails com texto puro.
- **Configuração via SMTP**: Permite o uso de serviços como Gmail.
